数据（存在本机，不上传）

菜谱、食材、周计划都保存在这台设备的浏览器里。换手机或清理浏览器数据前，请先导出备份文件。

怎么放到手机上用

  1. 把这个文件夹上传到 GitHub 仓库，打开 Settings → Pages，Source 选 main / (root)，保存后得到一个 https://用户名.github.io/仓库名/ 的网址。
  2. 手机上用浏览器打开这个网址。
  3. iPhone：点分享按钮 → 「添加到主屏幕」。安卓：菜单 → 「安装应用 / 添加到主屏幕」。之后就像 App 一样打开，断网也能用。
  4. 数据存在手机浏览器本地，换手机或清理浏览器数据会丢，先到上面「导出备份」存一份 json。

也可以直接用电脑/手机本地打开 index.html，功能完全一样（只有"添加到主屏幕"需要一个网址）。
